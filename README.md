# Don't Panic, It's Just the Matura – Writing Guide B2

A free, independent revision site for the written part of the English Matura in Austria (AHS and BHS, level B2). Live at **https://matura.bernhardgmeiner.com**.

No account, no tracking, no ads. Everything runs in the visitor's own browser.

## What it covers

- All the written text types – essay, article, report, blog, e-mail and leaflet – each with a guide, annotated model texts, useful phrases, a quiz and a sentence-ordering exercise.
- A switch between **AHS** and **BHS** that adjusts the tasks, timing and text types to each school type.
- Tools: a searchable phrase bank, a writing checklist, a self-check studio, a task bank with realistic prompts, and a topic-vocabulary trainer.
- Skills and practice: paragraph writing, a grammar kit for common German-to-English mistakes, a practice zone, an exam timer, and a "grade like an examiner" section that shows how the four assessment criteria are applied to real-style texts.
- Downloadable PDFs for every text type and the key overviews.

## How it's built

Plain HTML, CSS and vanilla JavaScript. No framework, no server, no database. The site works offline as a Progressive Web App, stores progress only in the visitor's browser (localStorage), and embeds its fonts locally, so it makes no external requests. It is hosted as a static site on GitHub Pages.

## Using it

The site is free for students to revise with and for teachers to use in class. It is an independent revision aid, not an official document of the BMB or any education authority. In the real Matura, your work is assessed by your teachers with the official scale.
